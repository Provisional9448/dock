**What the links are:** a carrier PRO tracking page (carrier code RKFX, demo) and a public container-status page. A new URL may track a different target, so treat it as a new watch unless it clearly refers to the same unit.

## Expected follow-ups
- Same rule as the earlier request: report arrival at the consignee.
- "Use the link again" means actually reopen it and report what it shows now. Don't claim a retry that never happened.
- A link that has expired is an open question for the client. It doesn't mean the load is "still in transit".
