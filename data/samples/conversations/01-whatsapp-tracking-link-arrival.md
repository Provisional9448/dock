# 01 — WhatsApp: tracking link + "tell me when it arrives"

> FICTIONAL SAMPLE. All names, codes and links are invented.

**Channel:** direct WhatsApp, client ops lead → Dock assistant
**From:** Sam Okafor (ops lead, Orchard Line Logistics — demo broker)

```
[Oct 13, 08:02] Sam: can u open tracking pages?
[Oct 13, 08:03] Sam: https://example.com/fleet/live/u1841-demo?share=7Q2KX
[Oct 13, 08:03] Sam: thats unit 1841 Red Kettle, load LL-88421
[Oct 13, 08:04] Sam: tell me once it gets to harbor & rye DC in Elizabeth
[Oct 13, 08:05] Sam: send location, hour and if its moving or parked
```

**What the link is:** a public telematics share link for one truck (live position, speed, last ping). It has no load number in it, so the load reference comes from the message text.

## Expected follow-ups
- One message when the truck reaches the consignee, not hourly "still in transit" pings.
- Each report gives the unit, the location, the source's last-ping time and the time the assistant checked, plus whether the truck is moving or stopped.
- If the page won't load or the map is blank, say so honestly and ask for a new link. Don't guess a location.
- Arrival means at the DC. "Near Elizabeth" is not arrival.
