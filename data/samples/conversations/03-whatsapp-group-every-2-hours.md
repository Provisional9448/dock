# 03 — WhatsApp: "adding you to the vendor group, report every 2 hours"

> FICTIONAL SAMPLE. All names, codes and links are invented.

**Channel:** direct WhatsApp, client ops lead → Dock assistant. It points to a group chat with the carrier.

```
[Oct 14, 07:03] Sam: putting you in the Red Kettle dispatch group, follow what they post and send me a summary each 2 hrs
[Oct 14, 07:06] Sam: plus this link is for ABCU1234567 reefer, include it
[Oct 14, 07:06] Sam: https://example.com/fleet/live/u1841-demo?share=9MZP4
```

## Expected follow-ups
- A scheduled report every 2 hours, written as one compact line per unit, for example:
  `LL-88421 / ABCU1234567 / I-80 near Joliet IL, moving / source ping 09:52 CT / checked 10:01 CT / next check 12:00 CT`
- If the link can't be verified, the report still goes out and says so: "could not verify, source time unavailable, recheck at 12:00".
- The assistant reads the carrier group but doesn't reply in it. Anything unusual goes to the client right away.
